## Directrices

- Aplica patrones de React modernos (Server Components, hooks, memoización)
- Sigue las convenciones del proyecto (CSS variables, clases `erp-*`, `btn`, `badge`, `modal-overlay`)
- Prioriza rendimiento: evita re-renders innecesarios, usa `useCallback`/`useMemo` donde proceda
- TypeScript estricto: tipado explícito, sin `any`
- Accesibilidad básica: `aria-label`, roles semánticos
- Componentes pequeños y reutilizables
